Manual test flows (planned)

1 · Auto-discovery → Verify

  1. CPE: call NMS connect API on device — device appears in NMS automatically
  2. BTS: configure NMS server IP on device — BTS appears in NMS automatically
  3. Verify displayed fields, onboarding, and auth-failure alarm behaviour

2 · Config → Verify

  1. Apply config or template from NMS
  2. Check job completes in GUI
  3. Verify settings on device via SSH
  4. Confirm change visible in inventory

3 · Fault → Alarm → Netcool

  1. Induce link/device fault in lab
  2. Confirm alarm in NMS in real time
  3. Verify Netcool receives raise/clear
  4. Export alarm history CSV/XLS
