Core manual validation flow
End-to-end NMS validation on lab hardware
1
Auto-discovery
  • CPE: call NMS connect API — device appears in NMS
  • BTS: set NMS server IP on device — hub appears in NMS
2
Inventory check
  • Verify fields, birth certificate & topology placement
  • Search, tag & export CSV/XLS for evidence
3
Config apply
  • Apply template or per-device config from NMS GUI
  • Confirm job completes & inventory reflects change
4
Device verify
  • SSH to BTS/CPE — confirm UCI & runtime state
  • Cross-check NMS display vs device ground truth
5
Fault & alarm
  • Induce link or device fault in lab
  • Confirm alarm raise/clear in NMS in real time
  • Export alarm history for sign-off evidence
