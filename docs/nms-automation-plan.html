Automated test flows (planned)

1 · Discovery → Inventory

  1. Trigger discovery by IP/MAC/serial via GUI
  2. Assert WebSocket device-appeared event
  3. Cross-check fields via SSH on device
  4. Verify inventory row and export file

2 · Config → Device state

  1. Apply template / bulk config from NMS
  2. Poll job status until complete
  3. Read UCI/network on CPE via Scrapli
  4. Confirm syslog reflects change

3 · Fault → Alarm → Netcool

  1. Inject link loss (Vaunix attenuation)
  2. WebSocket: alarm raised within SLA
  3. Kafka consumer: Netcool message
  4. Restore link; assert clear on both paths
